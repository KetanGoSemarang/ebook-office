Bab 1: Fondasi Office

1.1 Mengenal Ribbon, Quick Access, dan Status Bar

Office itu seperti kokpit pesawat. Terlalu banyak tombol, tapi kau hanya perlu 20% yang paling sering dipakai.

Ribbon

Deretan menu di atas (Home, Insert, Design). Fokus pada Home dan Insert.

Quick Access Toolbar (QAT)

Kotak kecil di pojok kiri atas. Tambahkan: Save, Undo, Redo, Print Preview.

Status Bar

Di bagian bawah. Klik kanan → aktifkan Page Number, Word Count, Zoom.

1.2 Menyimpan File

Jangan percaya autosave saja. Suatu hari kau akan menutup file tanpa menyimpan, dan autosave tidak menolong.
  1. Tekan Ctrl+S setiap selesai 1 paragraf.
  2. Simpan di 2 tempat: laptop + cloud.
  3. Gunakan versi: Laporan_v1.docx, Laporan_v2.docx.

1.3 Tampilan Nyaman untuk Mata

  • Zoom: Ctrl + scroll mouse. Atur 100–120%.
  • Dark Mode: File → Options → General → Office Theme → Dark Gray.
  • Sembunyikan penggaris: View → Ruler.

Latihan Mini (5 menit)

  1. Buka Word kosong.
  2. Tambahkan Save dan Print Preview ke Quick Access Toolbar.
  3. Ganti tema ke Dark Gray.
  4. Simpan file: Latihan_Office_1.docx.

Jika berhasil, kau sudah lebih maju dari 70% pengguna Office.

Bab 2: Word — Mesin Kata

2.1 Gaya (Style) — Rahasia Dokumen Rapi Instan

Kebanyakan orang memformat teks manual: bold, ukuran 14, warna biru, diulang 50 kali. Itu buang waktu.

Solusi: Style.

  1. Tulis judul → klik Heading 1.
  2. Tulis sub-judul → klik Heading 2.
  3. Teks biasa → klik Normal.

Keajaibannya:

  • Daftar isi otomatis muncul dalam 1 detik.
  • Ubah style Heading 1 → semua judul berubah serempak.

2.2 Daftar Isi Otomatis

  1. Pastikan semua judul pakai Heading 1, 2, 3.
  2. Letakkan kursor di halaman pertama.
  3. Klik References → Table of Contents → pilih gaya otomatis.
  4. Update setelah edit: klik daftar isi → Update Table.

2.3 Mail Merge — Satu Surat, Seribu Penerima

Bayangkan mengirim undangan ke 500 orang, tapi tiap surat menyebut nama mereka. Tanpa Mail Merge, kau akan gila.

Bahan: File Word (template) + File Excel (data penerima).

  1. Di Word: Mailings → Start Mail Merge → Letters.
  2. Select Recipients → Use an Existing List → pilih file Excel.
  3. Klik Insert Merge Field → pilih kolom.
  4. Preview Results → lihat surat pertama berubah.
  5. Finish & Merge → Edit Individual Documents → "All".

2.4 Tabel di Word — Tidak Harus Berantakan

  1. Insert → Table → max 5–6 kolom agar terbaca.
  2. AutoFit to Window — klik kanan → AutoFit.
  3. Header berulang — pilih baris pertama → Table Design → Header Row → Layout → Repeat Header Rows.
  4. Border tipis — hindari border tebal.

2.5 Rumus Sederhana di Tabel Word

  1. Kursor di sel hasil.
  2. Layout → Data → Formula.
  3. Tulis: =SUM(ABOVE) — jumlahkan semua angka di atas.
  4. Klik OK. Jika angka berubah, klik kanan → Update Field.

2.6 Makro — Rekam Tugas Berulang

  1. View → Macros → Record Macro.
  2. Beri nama: FormatLaporan.
  3. Lakukan tindakan (ubah font, margin, header).
  4. View → Macros → Stop Recording.
  5. Jalankan: View → Macros → View Macros → Run.

Latihan Bab 2 (15 menit)

  1. Buat surat undangan Mail Merge untuk 5 nama fiktif.
  2. Buat tabel daftar barang dengan 4 kolom, tambahkan rumus SUM.
  3. Rekam makro: ubah teks jadi Arial 12, spasi 1.5.
  4. Simpan: Latihan_Word_Hendri.docx.

Bab 3: Excel — Otak Angka

3.1 5 Rumus Wajib yang Menggantikan 50 Rumus

#1: XLOOKUP

=XLOOKUP("Hendri", A:A, C:C) → cari "Hendri" di kolom A, ambil dari kolom C.

#2: IFS

=IFS(A1>90,"A", A1>80,"B", A1>70,"C", TRUE,"D")

#3: SUMPRODUCT

=SUMPRODUCT(A2:A10, B2:B10) → A2*B2 + A3*B3 + ...

#4: TEXTJOIN

=TEXTJOIN(", ", TRUE, A2:A10) → gabung teks dengan koma.

#5: UNIQUE

=UNIQUE(B2:B100) → tampilkan nilai unik tanpa duplikat.

3.2 PivotTable — Laporan Ringkas Tanpa Rumus

  1. Pilih data (Ctrl+A).
  2. Insert → PivotTable → New Worksheet.
  3. Seret kolom: Rows: Kota, Columns: Produk, Values: Penjualan (SUM).
  4. Selesai.

3.3 Power Query — Bersihkan Data Kotor

  1. Data → Get Data → From File → From Text/CSV.
  2. Klik kanan kolom "Tanggal" → Change Type → Date.
  3. Hapus kolom tidak perlu → Remove.
  4. Close & Load ke worksheet baru.

3.5 Validasi Data — Cegah Salah Input

  1. Pilih sel/kolom.
  2. Data → Data Validation.
  3. Allow → List → Source: Jakarta, Bandung, Surabaya.
  4. Klik OK.

3.6 Conditional Formatting — Warnai Data Otomatis

  1. Pilih data.
  2. Home → Conditional Formatting → Highlight Cells Rules.
  3. Greater Than → 1000 → warna hijau.

Latihan Bab 3 (15 menit)

  1. Buat data 20 baris: Nama, Kota, Penjualan.
  2. Buat PivotTable: total per kota.
  3. Buat grafik batang dari PivotTable.
  4. Terapkan Conditional Formatting: penjualan > 5.000.000 → hijau.
  5. Simpan: Latihan_Excel_Hendri.xlsx.

Bab 4: PowerPoint — Panggung Ide

4.1 Master Slide — Desain Sekali, Pakai Selamanya

  1. View → Slide Master.
  2. Ubah font, warna, logo di slide paling atas.
  3. Tutup Master View.

Hasil: semua slide otomatis mengikuti desain.

4.2 5 Aturan Desain Slide

  1. Satu slide, satu ide.
  2. Teks maksimal 6 baris.
  3. Kontras tinggi: teks gelap, latar terang.
  4. Gambar > teks.
  5. Font konsisten (max 2 jenis).

4.3 Animasi yang Menolong, Bukan Mengganggu

  • Gunakan Fade atau Appear — jangan Fly In, Bounce, Spin.
  • Animasi hanya untuk: menampilkan poin satu per satu, menyorot data penting.
  • Transisi: cukup Fade atau Push.

4.4 Menyisipkan Excel & Word dengan Elegan

Dari Excel: Copy data → Paste Special → Excel Worksheet Object.

Dari Word: Copy → Paste Special → Formatted Text (RTF).

Latihan Bab 4 (15 menit)

  1. Buat Master Slide: logo di pojok kanan atas, font Montserrat.
  2. Buat 5 slide: Judul, Agenda, 3 Konten.
  3. Terapkan animasi Fade pada poin konten.
  4. Simpan: Latihan_PPT_Hendri.pptx.
